# pattern-playbook

对照 TA-Lib 识别的 K 线形态与用户上传的技术分析 / 形态 / 走势资料，判断标的是否像某类形态，并给出关键位与失效条件。

## 步骤

1. **有股票代码时**：先调用 `get_candlestick_patterns`（默认近 30 日、只返回命中）。
   - 想聚焦某形态时可传 `patterns`（如 `["CDLENGULFING","早晨之星"]`）或加大 `lookback_bars`。
   - `value>0` 偏多、`value<0` 偏空（TA-Lib 惯例）。无 TA-Lib / 无日线时如实说明，不得编造信号。
2. **再读**系统中的「知识库预检索」区块；不足时调用 `search_knowledge`，用形态中文名作关键词。
3. **严格引用**笔记/书籍原文规则；把机器命中与笔记定义对照，指出一致或冲突处。
4. 可用其它只读工具辅助（`get_valuation`、`get_financials` 等）；禁止编造未返回的数字。
5. 输出建议结构：
   - TA-Lib 近期命中摘要
   - 与知识库的对照（附依据）
   - 确认/观察要点、关键位与失效条件（仅当资料中有，或标明为通用常识）
   - 风险：形态主观，不构成投资建议，不保证胜率
6. 禁止下单；禁止把笔记历史案例当成该股已发生的事实。

## 示例问法

- 「600519 近一个月有哪些 K 线形态？对照我的笔记怎么看？」
- 「只要吞没和早晨之星，帮我看下宁德。」
