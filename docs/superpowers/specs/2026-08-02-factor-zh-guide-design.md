# 因子中文说明补全（三段式）

> 状态：已实现  
> 日期：2026-08-02

## 目标

为系统内**全量** TA-Lib 注册因子、周期别名与价格/量伪因子补全详细中文说明；列表仍显示短名，点「说明」展示：**含义 → 怎么用 → 注意点**（约 80～200 字）。

## 决策摘要

| 项 | 选择 |
|----|------|
| 范围 | 全量（方案 B） |
| 文案结构 | 三段式短文（方案 A） |
| 短名 | 保留现有 `TALIB_ZH_DESC` 作 `label` |
| 详述 | 新表 `TALIB_ZH_GUIDE` → API `description` |
| ML 因子 | 不改（仍跟模型元数据） |
| 迅投因子 | 不接 |

## 文案格式

```text
【含义】……
【怎么用】……
【注意点】……
```

- 总长约 80～200 字（可略超，避免百科长文）。
- 周期别名（如 `RSI_14`）：详述可复用基函数 + 一句「默认周期 14」。
- `CDL*`：写清形态外观与多空倾向；输出多为 0/±100 信号。

## 架构

| 单元 | 职责 |
|------|------|
| `packages/factor/desk_factor/zh_desc.py` | 保留短名 |
| `packages/factor/desk_factor/zh_guide.py` | `TALIB_ZH_GUIDE` + `zh_guide_for_talib()` |
| `packages/factor/desk_factor/registry.py` | `label`←短名；`description`←详述（无则回退短名） |
| `apps/web` 说明弹层 | 按【含义】【怎么用】【注意点】分节或保留换行展示 |
| 规则构建器下拉 | **只用 `label`/name**，勿把长 `description` 塞进选项主文案；搜索仍可匹配 description |

## 非目标

- 改因子计算、策略求值
- 每条附完整数学推导
- 同步英文文档站

## 测试

1. 每个注册 `talib` 名在 `TALIB_ZH_GUIDE` 有条目（或显式回退策略有测）。
2. `get_factor("RSI").description` 含「含义」与「怎么用」。
3. `label` 仍为短中文，不含「【含义】」。

## 手工验收

- 因子页点「说明」：三段可读。
- 左栏勾选行标题仍短。
- 规则构建器选项不出现大段说明正文。
