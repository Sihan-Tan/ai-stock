# 分时可配置槽宽轮询（混合分钟线 + 报价补点）

> 状态：待实现  
> 日期：2026-08-01

## 目标

分时主图与副图（成交量 / MACD / 资金趋势）使用**槽宽 = 刷新间隔**的时间轴；历史用分钟线铺底，盘中按设置间隔用报价快照补点。间隔在系统设置中持久化，默认 10 秒，范围 5～60。

## 决策摘要

| 项 | 选择 |
|----|------|
| 数据形态 | 混合：分钟线历史 + 报价快照补点 |
| 槽宽 | **等于** `intraday_poll_interval_sec`（非固定 10s 轴） |
| 默认间隔 | 10 秒 |
| 合法范围 | 整数 **5～60**；非法回退 10 |
| 设置存放 | `/api/settings` + Settings 页（方案 A） |
| 副图 | 与主图共用同一加密序列（MACD / 资金趋势随槽变化） |
| 分钟线补刷 | 约 30～60s 一次（与快照解耦） |

## 非目标

- 后端落库 10 秒 K / tick 推送
- WebSocket
- 改日 / 周 / 月 K
- 集合竞价段单独更高频（仍映射到槽）

## 设置项

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `intraday_poll_interval_sec` | int | 10 | 分时槽宽兼报价轮询间隔（秒） |

落地：

- `desk_common.settings.Settings` 字段 + env `INTRADAY_POLL_INTERVAL_SEC`
- `settings_store`：`FIELD_TO_ENV` / `public_settings` / `apply_settings_patch`（clamp 5–60）
- `apps/api` `SettingsPatch` 增加可选字段
- 前端 `Settings.tsx`：行情或展示相关分组中增加数字输入「分时刷新间隔（秒）」

## 时间轴

设槽宽 `S = intraday_poll_interval_sec`（秒）。

- A 股会话（含竞价前缀、跳过午休）按秒展开后，每 `S` 秒一格。
- 伪时间：`INTRADAY_TIME_BASE + slotIndex`（与现网一致用整数轴，刻度格式化仍映回 HH:mm[:ss]）。
- `S` 变化时：用分钟线重映射 + **清空**本次页面盘中补点，再按新 `S` 轮询。

### 分钟线映射

- 每根分钟 bar 的 `ts` 落到「该分钟起点所在槽」：`close`（及 high/low/open/volume 按槽聚合：同槽多分钟以后写覆盖或 OHLC 合并，首版**后写覆盖 close、volume 取后者**即可）。
- 占位：全天所有槽先占位（类似现 `buildIntradaySessionPlaceholders`），保证关键时刻刻度。

### 报价补点

- 每 `S` 秒请求 `/api/market/intraday/quote`，取 `last`（或等价现价字段）。
- 按**当前北京时间**落入的槽写入/更新 `value=last`（主分时 Area）。
- 同槽重复轮询：更新该槽价格（Y 轴跟手），不新增重复 time。

### 分钟线补刷

- 另一定时（建议 `max(30, S)` 秒，上限 60）拉 `/bars/minute`，重铺历史槽，**保留**仍落在「最后一根完整分钟之后」的盘中补点（或简化：重铺后仅保留「当前未完成分钟」内的补点）。
- 首版可接受：分钟重拉后用「分钟映射 ∪ 当前槽报价」重建，实现简单。

## 副图

| 副图 | 行为 |
|------|------|
| 成交量 | 基于槽序列的 volume（分钟映射带量；纯报价补点无量则 0 或不画该点） |
| MACD | 对槽上 close 序列计算（点更密，线更跟手） |
| 资金趋势 | `buildIntradayFundFlow` 输入改为槽序列对应的伪分钟/`OhlcvBar` 列表（close=槽价；高开低可用 close）；指数侧：预热仍分钟线映射到同槽轴，盘中可用指数报价快照按同 `S` 补点（若有）；无指数快照时大盘列用最近指数槽 |

预热（约 5 交易日）仍服务 EMA/HHV；**仅当日槽**上图。预热日按分钟映射到「虚拟连续槽」或仅在当日用槽轴、预热用顺序下标算指标（与现 fund/dip 顺序轴 EMA 策略一致即可）。

## 前端数据流

1. 进入分时：读 settings → `S`；拉分钟线 + 报价；建槽序列。
2. `setInterval(S*1000)`：拉报价 → 更新当前槽 → 刷新图（主图+副图）。
3. 较慢定时：拉分钟线 → 重建底图 ∪ 补点。
4. 设置变更（同页或重新进入详情）：应用新 `S` 并重建。

`StockDetailView` / `StockChart`：`slotSec`（或 `pollIntervalSec`）作为 props；`format.ts` 提供 `toAshareSessionSlot(hour,minute,second,slotSec)` 等。

## 测试

1. settings：clamp —— 4→10 或拒绝并文档化为 clamp 到 5；61→60 或 10（实现选 **clamp 到 [5,60]**）。
2. 槽索引：09:30:00 @ S=10 → 与 09:30:09 同槽；09:30:10 下一槽。
3. 分钟映射：一根 09:31 bar 落到 09:31:00 所在槽。
4. 回归：日 K 不受影响；`S=60` 时行为接近现网分钟轴。

### 手工验收

- 默认 10s：分时线约每 10 秒跟价。
- 设置改为 5 / 30 并保存：详情分时槽密度与轮询变化。
- MACD / 资金趋势随主图更新。
- 非交易日回退日：仍按会话日分钟铺底，补点仅在「有报价且时间落在会话」时写入。

## 风险

- `S=5` 全天槽数约为现网 6 倍，图表性能需留意（lightweight-charts 一般可承受）。
- 报价与分钟 close 短暂不一致：以补点为准更新当前槽。
- 副图指标在稀疏报价段（无量）时 volume/部分公式退化：可接受。
