# 规则条件因子可搜索选择（Combobox）

**日期：** 2026-07-23  
**状态：** 已实现  
**入口：** 策略规则构建器 → 条件左右操作数（因子）

## 目标

规则条件里选因子时支持输入过滤，避免在超长原生 `<select>` 中翻找。

## 已确认决策

| 项 | 选择 |
| --- | --- |
| 范围 | 仅规则构建器 `OperandEditor` 因子位 |
| 形态 | 方案 A：本地 Combobox（输入 + 过滤下拉） |
| 匹配字段 | `name` / `label` / `description`（大小写不敏感包含） |
| 不做 | 因子目录页改动、引入新 UI 库、常数位搜索 |

## 行为

- 未打开：显示当前已选因子标签（与现 label 格式一致）
- 聚焦/点击：展开列表；输入时按关键字过滤
- 选中一项：回写因子名并关闭
- 无匹配：提示「无匹配因子」
- 已选但不在 options 中：仍展示原值并可保留

## 实现要点

- `factorOptions` 增加 `searchText`（或等价）供过滤
- 用 `FactorOperandCombobox` 替换因子位原生 `<select>`
- 轻量 vitest：过滤函数纯逻辑（可选）
